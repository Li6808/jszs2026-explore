# 教师助手 · 探索版（jszs2026-explore）

这是「教师个人助手」的**探索版**，用来试新东西：首页改二级菜单（教师管理 / 班级管理），
新增「班级学生名单」和「职称材料（打怪晋级）」两个模块。正式版在
<https://github.com/Li6808/jszs2026>，通用版在 <https://github.com/Li6808/jszs2026-lite>。

- 本仓库只有构建产物，源码不在这里。
- **数据完全独立**：浏览器里用的存储键跟正式版不一样，同一台设备上两版可以共存、互不影响。
- 想把自己正式版的数据搬过来：正式版「个人设置 → 数据备份与恢复 → 导出」，再到探索版导入。
